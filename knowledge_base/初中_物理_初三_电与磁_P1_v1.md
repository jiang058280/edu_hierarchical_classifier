## 第 1 单元｜电流和电路（串并联）

### 学习目标

1. 能说出电流的形成、方向的规定与电流的单位换算，会正确使用电流表；
2. 能识别串联电路与并联电路，说出两种电路中电流、电压的特点；
3. 能根据电流方向判断电路是否通断，并会画简单电路图、连接实物电路。

### 核心知识

**电流。** 电荷的定向移动形成电流。规定**正电荷定向移动的方向**为电流方向；在电源外部，电流从电源正极经用电器流向负极。电流用 I 表示，单位安培（A），1 A = 1000 mA，1 mA = 1000 μA。

**电流表的使用。** 电流表必须**串联**在被测电路中；电流必须从"+"接线柱流入、"−"接线柱流出；被测电流不得超过量程（常用 0～0.6 A 与 0～3 A 两档，0～0.6 A 档每小格 0.02 A，0～3 A 档每小格 0.1 A）；**严禁把电流表直接接到电源两极**。

**串联电路的特点。** 电流处处相等：I = I₁ = I₂；总电压等于各部分电压之和：U = U₁ + U₂；开关控制整个电路，位置不影响其作用；一个用电器断路，整个电路即断路。

**并联电路的特点。** 干路电流等于各支路电流之和：I = I₁ + I₂；各支路两端电压相等且等于电源电压：U = U₁ = U₂；各支路互不影响，干路开关控制整个电路，支路开关只控制本支路。

**短路。** 电源短路（用导线直接把电源两极连通）会因电流过大烧坏电源，**严禁**；用电器短路（导线与用电器并联）会使该用电器不工作。

### 常见误区

1. **认为电流从负极流向正极。** 错误原因：把电子移动方向当作电流方向。电流方向按规定为正电荷定向移动的方向，与电源外部电子移动方向相反。
2. **把电流表并联在电路两端。** 错误原因：忽略电流表内阻极小。并联会使电流表直接接在电源两极附近，造成电流过大而损坏仪表，电流表必须串联。
3. **认为串联电路中电流"越流越小"。** 错误原因：误把"用电器的先后"理解为"消耗电流"。串联电路中各处的电流完全相同，被消耗的是电能而不是电流。

### 小结

1. 记牢三个"规定"：电流方向由正电荷定向移动方向规定；电源外部电流由正极到负极；电流表串联且电流"正入负出"。

## 第 2 单元｜电压与电阻

### 学习目标

1. 能说出电压的作用、单位，会正确使用电压表并选择合适的量程；
2. 能说出决定电阻大小的因素，理解电阻是导体本身的一种性质；
3. 能说明滑动变阻器的构造、原理与正确接法，并会分析其在电路中的作用。

### 核心知识

**电压。** 电压是使电路中形成电流的原因，电源是提供电压的装置。电压用 U 表示，单位伏特（V），1 kV = 1000 V，1 V = 1000 mV。常见电压值：一节干电池 1.5 V，家庭电路 220 V，对人体安全的电压不高于 36 V。

**电压表的使用。** 电压表必须**并联**在被测用电器两端；电流从"+"接线柱流入、"−"接线柱流出；量程常用 0～3 V（每小格 0.1 V）与 0～15 V（每小格 0.5 V）。**电压表可以直接接到电源两极测电源电压**（这一点与电流表不同）。

**电阻。** 电阻表示导体对电流阻碍作用的大小，用 R 表示，单位欧姆（Ω）。电阻是**导体本身的一种性质**，其大小由导体的**材料、长度、横截面积**决定，还与温度有关；与导体两端的电压、通过的电流**无关**（同一导体两端电压增大时电流随之增大，但 R 不变）。

**决定电阻的因素规律。** 材料、横截面积相同时，导体越长电阻越大；材料、长度相同时，横截面积越大电阻越小；其他条件相同时，不同材料的电阻不同。常见的半导体（如硅、锗）电阻随温度升高而减小，可用于制作热敏电阻。

**滑动变阻器。** 原理是**通过改变接入电路中电阻线的长度来改变电阻**。正确接法是"一上一下"（两个接线柱分别接上方一个、下方一个）；接"两上"或"两下"都不会变阻。移动滑片时要注意接入的是哪一段电阻线。

### 常见误区

1. **认为导体两端电压为零时电阻为零。** 错误原因：把电阻与电压挂钩。电阻由导体本身决定，电压为零时电阻依旧存在，电流为零只是因为没有电压推动电荷。
2. **电压表串联接入电路。** 错误原因：混淆电压表与电流表的连接方式。电压表内阻很大，串联后电路电流极小，用电器不工作，必须并联。
3. **滑动变阻器接成"两上"或"两下"。** 错误原因：未理解"一上一下"的道理。接两下相当于一段固定电阻（不能变阻），接两上相当于一根导线（电阻为零），两者都失去变阻作用。

## 第 3 单元｜欧姆定律及应用

### 学习目标

1. 能说出欧姆定律的内容与表达式，并明确其适用条件（同一导体、同一时刻）；
2. 会进行 I = U/R 及其变形公式的简单计算，正确处理串、并联电路的总电阻；
3. 能分析滑动变阻器改变电路时电流与电压的变化，会判断电表示数变化。

### 核心知识

**欧姆定律。** 导体中的电流，跟导体两端的电压成正比，跟导体的电阻成反比，即 **I = U/R**。变形式 U = IR、R = U/I 只表示数量关系，**不能说"电阻与电压成正比、与电流成反比"**。

**串联电路的总电阻。** R总 = R₁ + R₂（串联相当于增大导体长度，总电阻大于其中任何一个电阻）。电流 I 相同，各电阻分得的电压与其阻值成正比：U₁ : U₂ = R₁ : R₂。

**并联电路的总电阻。** 1/R总 = 1/R₁ + 1/R₂，即 R总 = R₁R₂/(R₁+R₂)，总电阻小于其中任何一个电阻。各支路电压相同，电流与其阻值成反比：I₁ : I₂ = R₂ : R₁。

**动态电路分析方法。** 步骤为：先判断电路连接方式（串/并）与各表测量对象→再看滑动变阻器滑片移动时接入电阻如何变化→然后由欧姆定律判断总电流、各部分电压的变化。口诀：**串联"阻变→流变→压变"，并联支路互不影响。**

**伏安法测电阻。** 用电压表测 U、电流表测 I，由 R = U/I 计算。多次测量取平均值以减小误差；测量小灯泡电阻时会发现其阻值随温度升高而变大。

### 常见误区

1. **由 R = U/I 得出"电阻与电压成正比、与电流成反比"。** 错误原因：把数学变形当作物理规律。R 由导体本身决定，U 与 I 的比值只是一个测量结果。
2. **并联电路总电阻的判断错误。** 错误原因：按串联思维相加。并联相当于增大横截面积，总电阻必然**小于**任何一个支路电阻。
3. **动态电路分析时忘记"电源电压不变"。** 错误原因：忽略隐含条件。分析时须牢记电源电压恒定、定值电阻阻值不变，仅滑动变阻器接入部分变化。

## 第 4 单元｜电功率与焦耳定律

### 学习目标

1. 能说出电功、电功率的物理意义、单位及计算公式，会计算电能与电费；
2. 会运用 P = UI、P = I²R、P = U²/R 解决串并联电路中的功率问题；
3. 能说出焦耳定律的内容与表达式，区分纯电阻与非纯电阻用电器的电热计算。

### 核心知识

**电功与电功率。** 电流做的功叫电功，W = UIt，单位焦耳（J），生活中常用千瓦时（kW·h），1 kW·h = 3.6×10⁶ J。电功率表示消耗电能的快慢，**P = W/t = UI**，单位瓦特（W），1 kW = 1000 W。由 P = UI 结合欧姆定律可得 **P = I²R = U²/R**（后两式仅适用于纯电阻电路）。

**额定功率与实际功率。** 用电器铭牌上标的是额定电压与额定功率（如"220 V 100 W"），指正常工作时的值。实际电压低于额定电压时实际功率小于额定功率；**灯的亮度由实际功率决定**，而不是额定功率。

**焦耳定律。** 电流通过导体产生的热量 **Q = I²Rt**。纯电阻用电器（电饭锅、电热丝）W = Q，电热可由任意相应公式计算；非纯电阻用电器（电动机、电视机）W > Q，只能用 Q = I²Rt 计算电热。

**串并联中的功率分配。** 串联时各电阻电流相同，P₁ : P₂ = R₁ : R₂（电阻大的发热功率大）；并联时各支路电压相同，P₁ : P₂ = R₂ : R₁（电阻小的消耗功率大）。

### 常见误区

1. **对电动机用 P = U²/R 计算电热。** 错误原因：忽略"纯电阻"条件。电动机把大部分电能转化为机械能，电热只能用 Q = I²Rt。
2. **认为额定功率大的灯泡一定更亮。** 错误原因：混淆额定与实际。灯泡亮度取决于实际功率，两只灯串联时往往额定功率小的反而更亮（其电阻大、分得电压多）。
3. **单位混用导致数量级错误。** 错误原因：未统一单位。计算电能时须把时间化为秒（或用 kW·h 与 kW 配对），1 kW·h = 3.6×10⁶ J 不能混淆。

## 第 5 单元｜电和磁（电流磁效应与电磁感应）

### 学习目标

1. 能说出奥斯特实验的意义，会用安培定则判断通电螺线管的磁极；
2. 能说明电磁铁的磁性强弱与电流大小、线圈匝数、有无铁芯的关系；
3. 能说出电磁感应现象、产生感应电流的条件与影响感应电流方向的因素，并说出电动机、发电机的工作原理。

### 核心知识

**电流的磁效应。** 奥斯特实验表明**通电导线周围存在磁场**，磁场方向与电流方向有关。通电螺线管外部磁场与条形磁体相似，其磁极可用**安培定则**判断：用右手握螺线管，让四指指向电流方向，则大拇指所指的一端为 N 极。

**电磁铁。** 电磁铁由通电线圈和铁芯组成。磁性强弱与**电流大小、线圈匝数、有无铁芯**有关：电流越大、匝数越多、有铁芯，磁性越强。电磁铁的优点是可**通过电流的通断和大小来控制磁性**，应用于电磁起重机、电铃、电磁继电器等。

**磁场对通电导体的作用。** 通电导体在磁场中会受到力的作用，受力方向与**电流方向、磁场方向**都有关系。**电动机**就是利用"通电导体在磁场中受力而运动"的原理制成的，工作时把电能转化为机械能。

**电磁感应。** 闭合电路的一部分导体在磁场中做**切割磁感线运动**时，导体中就会产生电流，这种现象叫电磁感应，产生的电流叫感应电流。感应电流的方向与**导体运动方向、磁场方向**有关。**发电机**就是根据电磁感应原理制成的，工作时把机械能转化为电能。

**对比记忆。** 电动机：电生运动（通电受力）；发电机：运动生电（切割磁感线）。二者原理恰好互为"逆向"。

### 常见误区

1. **认为只要导体在磁场中运动就产生感应电流。** 错误原因：忽略两个条件。必须是**闭合电路的一部分**导体，且做**切割磁感线**运动；沿磁感线方向平行运动不产生感应电流。
2. **混淆电动机与发电机的原理。** 错误原因：不辨能量转化方向。电动机是"通电受力"（电能→机械能），发电机是"切割生电"（机械能→电能）。
3. **安培定则操作错误。** 错误原因：四指与电流方向对应关系搞反。四指必须顺着电流方向环绕，大拇指所指才是 N 极。

## 第 6 单元｜电磁波与信息传递

### 学习目标

1. 能说出电磁波的产生、传播特点与波速公式 c = λf；
2. 能说出电磁波在真空中的传播速度，知道电磁波谱的组成与常见应用；
3. 能说明现代通信中光纤通信、卫星通信的基本过程，理解信息传递方式的演进。

### 核心知识

**电磁波的产生与传播。** 迅速变化的电流（振荡电流）能在周围空间产生电磁波。电磁波**不需要介质**，可以在真空中传播；在真空中传播速度 c = 3×10⁸ m/s，与光速相同——**光也是电磁波**。

**波速公式。** c = λf（波速 = 波长 × 频率）。波速一定时，波长与频率成反比：频率越高，波长越短。

**电磁波谱。** 按频率由低到高（波长由长到短）大致分为：无线电波、微波、红外线、可见光、紫外线、X 射线、γ 射线。**频率越高，波长越短，穿透能力通常越强。** 应用：微波用于微波炉与卫星通信；红外线用于遥控器、热成像；紫外线用于杀菌消毒；X 射线用于透视检查。

**现代通信。** ①电话：把声信号转化为电信号，通过导线传输；②光纤通信：利用激光在光导纤维中传播，携带信息量大、抗干扰强、损耗小；③卫星通信：利用微波经通信卫星（同步卫星）转发，可实现远距离与跨洋通信；④网络通信：把计算机等设备连成网络，实现信息的快速交换与共享。

**传递信息的载体演变。** 从烽火、驿马到电报、电话，再到电话网、计算机网络与移动通信，信息传递的速度、容量与可靠性不断提高。

### 常见误区

1. **认为电磁波传播需要介质。** 错误原因：与声波混淆。声波是机械波，必须依靠介质；电磁波可以在真空中传播，所以宇航员在太空可用电磁波通信。
2. **认为频率越高波长越长。** 错误原因：忘记 c = λf 中波速基本不变。真空（空气）中波速相同，频率与波长成反比。
3. **把微波与"声波"混为一谈。** 错误原因：名称带"波"字。微波属于电磁波，微波炉靠使水分子剧烈振动生热来加热食物，不是"发出声音加热"。

### 题目 4｜实验探究题｜难度 2
- 题目编号：CZ-WL-C3-DB-004
- 学段：初中
- 年级：初三
- 学科：物理
- 题型：实验探究题
- 模型粗粒度题型：解答题
- 一级知识点：物理::电磁学
- 细粒度知识点：电磁波与信息传递
- 难度：2
- 认知层次：理解
- 建议作答时长：6 分钟
- 题干：
  小明想验证"电磁波可以在真空中传播，而声音不能在真空中传播"。他设计了如下实验：

  实验一：把正在响铃的手机放入玻璃罩内，逐渐抽出罩内空气，听到铃声明显减弱，抽成"真空"后几乎听不到声音。
  实验二：把正在响铃的手机放入同一玻璃罩内，用另一部手机拨打它，发现罩内手机屏幕亮起、能接通，通话正常。

  （1）实验一说明了什么？
  （2）实验二中罩内手机与外界通话依靠的是什么？说明了什么？
  （3）综合两个实验，比较声波与电磁波在传播条件上的区别。
- 选项：
  无
- 参考答案：
  （1）实验一说明声音的传播需要介质（空气），真空不能传声。（2）实验二中手机通话依靠电磁波（微波）传递信息，说明电磁波可以在"接近真空"的环境中传播，不需要介质。（3）声波是机械波，传播必须依靠介质，真空不能传声；电磁波可在真空中传播，不需要介质。正因如此，宇航员在太空舱外或在月球上只能依靠电磁波（无线电）通信。
- 解析：
  两个实验构成对照：抽气后铃声减弱，说明声音依赖空气传播；同一真空环境下手机仍能通话，说明手机依靠的电磁波不依赖空气。对比后即可得出"声波需要介质、电磁波不需要介质"的结论。答题要抓住"对照"二字，避免只描述现象而不作比较。
- 评分要点：
  总分 10 分。（1）答出"声音传播需要介质（真空不能传声）"得 3 分；（2）答出"电磁波（微波）"得 2 分，"电磁波不需要介质"得 2 分；（3）准确比较两者传播条件差异得 3 分（仅说"不一样"不得分）。
- 标签：初中；初三；物理；物理::电磁学；电磁波与信息传递；实验探究题；难度2

### 小结

1. 电磁波"三特征"：由迅速变化的电流产生、不需介质、真空中速度 3×10⁸ m/s。
2. c = λf 是电磁波计算的核心关系式；波速不变时频率与波长成反比。
3. 记住电磁波谱的用途对应：红外遥控、紫外消毒、X 射线透视、微波加热与通信。
