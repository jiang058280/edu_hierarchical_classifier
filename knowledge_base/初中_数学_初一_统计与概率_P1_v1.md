## 第 1 单元｜数据的收集与整理

### 学习目标

1. 能区分全面调查（普查）与抽样调查，会根据调查对象的特点选择合适的调查方式；
2. 能说出总体、个体、样本、样本容量的含义，在具体问题中准确识别这四个概念；
3. 能计算频数与频率，理解"各部分频率之和等于 $1$"，并会用频数分布表整理数据。

### 核心知识

**全面调查与抽样调查。** 对全体对象进行调查的方式叫全面调查（普查）；从总体中抽取一部分对象进行调查的方式叫抽样调查。当调查对象数量较少、不需要破坏性试验、且对结果精度要求高时，适合全面调查；当调查对象数量庞大、调查具有破坏性或受限于时间与成本时，适合抽样调查。选择调查方式要综合考虑对象规模、可行性以及是否具有破坏性。

**总体、个体、样本与样本容量。** 所要考察对象的全体叫总体，总体中的每一个考察对象叫个体，从总体中抽取的一部分个体叫样本，样本中个体的数目叫样本容量。需要注意：总体和样本都是指"考察对象"的集合，而样本容量是一个不带单位的纯数值。例如考察学生的身高时，总体是全体学生的身高数据的集合，不是学生本人。

**频数与频率。** 在分组整理数据时，每个小组内数据的个数叫该组的频数，频数与数据总数的比叫该组的频率。频率 $=\dfrac{\text{频数}}{\text{数据总数}}$，所有小组的频数之和等于数据总数，所有小组的频率之和等于 $1$。频数反映各组数据的绝对数量，频率反映各组数据所占的比例。

**适用边界与易混点。** "总体"与"样本"都是数据的集合而不是人或物的集合；样本容量不带单位；抽样调查要注意样本的代表性，样本抽取应具有随机性，不能只取某一类特殊对象。

### 常见误区

1. **把"总体"理解成人的集合。** 错误原因：混淆考察对象与承载对象。如考察学生身高时，总体是"全校学生身高的全体"，而不是"全校学生"。区分方法是看调查的具体指标是什么。
2. **样本容量带单位。** 错误原因：把样本容量与样本混淆。样本容量是样本中个体的数目，是纯数值，如"抽取了 $50$ 名学生"中样本容量是 $50$，不能写成"$50$ 名学生"。
3. **认为频率可以大于 $1$。** 错误原因：不理解频率的定义。频率 $=\dfrac{\text{频数}}{\text{数据总数}}$，频数不超过数据总数，故频率不超过 $1$；所有组的频率之和恒为 $1$。

## 第 2 单元｜统计图表（条形图、扇形图、折线图）

### 学习目标

1. 能说出条形统计图、扇形统计图、折线统计图的特点与适用场景，会根据数据特征选择合适的统计图；
2. 会从扇形统计图中读取百分比与圆心角的关系，能进行"圆心角—百分比—频数"之间的换算；
3. 能综合运用统计图表分析数据，补全缺失信息并作出合理判断。

### 核心知识

**三种统计图的特点。** 条形统计图用条形的高度表示各类别的频数，能直观反映各组的具体数量，便于比较大小；扇形统计图用扇形面积表示各部分占总体的百分比，能直观反映各部分所占的比例关系；折线统计图用线段的升降表示数据随时间或顺序的变化趋势，适合反映数据的变化规律。

**扇形统计图的圆心角。** 扇形统计图中，每个部分对应的圆心角 $=$ 该部分的百分比 $\times 360°$。反之，由圆心角可求百分比：百分比 $=$ 圆心角 $\div 360°$。各扇形圆心角之和等于 $360°$，各部分百分比之和等于 $1$（即 $100\%$）。

**由扇形图求频数。** 已知总数与某部分的圆心角（或百分比），可求该部分的频数：频数 $=$ 总数 $\times$ 百分比 $=$ 总数 $\times\dfrac{\text{圆心角}}{360°}$。反之，已知频数与总数可求百分比，再求圆心角。

**适用边界与易混点。** 扇形统计图能反映比例但不能直接反映具体数量，需要结合总数才能算出频数；条形图能反映数量但不直接反映比例；两种图配合使用时，可由一种图的已知量推算另一种图的未知量。

### 常见误区

1. **把扇形圆心角直接当作百分比。** 错误原因：混淆角度与比例。圆心角 $36°$ 对应的百分比是 $\dfrac{36}{360}=10\%$，而不是 $36\%$；换算必须除以 $360°$。
2. **扇形图中只知百分比就求频数。** 错误原因：遗漏总数。频数 $=$ 总数 $\times$ 百分比，没有总数无法求频数。若题目给出扇形图与条形图结合，通常需先由条形图读取某部分频数，再结合扇形图百分比求总数。
3. **折线图横轴不按时间顺序排列。** 错误原因：忽视折线图反映变化趋势的前提是横轴有序。横轴应按时间或顺序排列，否则折线的升降无意义。

- 学科：数学
- 题型：计算题
- 模型粗粒度题型：解答题
- 一级知识点：数学::排列组合与概率统计
- 细粒度知识点：统计图表（条形图、扇形图、折线图）
- 难度：3
- 认知层次：应用
- 建议作答时长：5 分钟
- 题干：
  某班 $40$ 名学生的一次数学测验成绩的频数分布表如下（部分数据缺失），请计算缺失的频数和频率，并补全表格。

  | 分数段 | 频数 | 频率 |
  | --- | --- | --- |
  | $60\sim70$ | $6$ |  |
  | $70\sim80$ |  | $0.25$ |
  | $80\sim90$ | $14$ |  |
  | $90\sim100$ |  |  |
- 选项：
  无
- 参考答案：
  $60\sim70$：频率 $0.15$；$70\sim80$：频数 $10$；$80\sim90$：频率 $0.35$；$90\sim100$：频数 $10$，频率 $0.25$。
- 解析：

## 第 3 单元｜平均数、中位数与众数

### 学习目标

1. 能说出平均数、中位数、众数的含义，并会计算一组数据的这三种统计量；
2. 能区分算术平均数与加权平均数，会按给定的权重计算加权平均数；
3. 能分析数据变化（如增加或删除一个数据）对平均数、中位数、众数的影响，并能根据实际情境选择合适的统计量描述数据。

### 核心知识

**平均数。** 一组数据的总和除以数据的个数，叫这组数据的算术平均数，记作 $\bar{x}$。加权平均数是在计算平均数时给每个数据赋予不同的权重（重要程度），公式为 $\bar{x}=\dfrac{x_1f_1+x_2f_2+\cdots+x_nf_n}{f_1+f_2+\cdots+f_n}$，其中 $f_i$ 是第 $i$ 个数据的权重。平均数利用了所有数据的信息，但容易受极端值（特别大或特别小的数据）的影响。

**中位数。** 将一组数据按从小到大（或从大到小）的顺序排列后，位于最中间位置的数据叫中位数。当数据个数为奇数时，中位数是第 $\dfrac{n+1}{2}$ 个数据；当数据个数为偶数时，中位数是最中间两个数据的平均数。中位数不受极端值影响，适合描述数据的中等水平。

**众数。** 一组数据中出现次数最多的数据叫众数。一组数据的众数可能不止一个，也可能没有（当所有数据出现次数相同时）。众数反映数据的集中趋势，常用于关注"最常见值"的场景，如鞋店关注哪种尺码销量最大。

**三种统计量的联系。** 平均数、中位数、众数都是描述数据集中趋势的统计量。平均数受所有数据影响，最灵敏但易受极端值干扰；中位数和众数不受极端值影响，但分别只反映位置信息和频数信息。在实际问题中，应根据数据特点和分析目的选择合适的统计量。

**适用边界与易混点。** 求中位数前必须先排序，不排序直接取中间是常见错误；偶数个数据的中位数是中间两个数的平均值，不是任取其中一个；众数是数据本身（原始数值），不是出现的次数。

### 常见误区

1. **求中位数时不排序。** 错误原因：忽视中位数定义中"排序"的前提。如数据 $3,1,4,1,5$ 应先排成 $1,1,3,4,5$，中位数是 $3$；不排序直接取第三个数 $4$ 则出错。
2. **偶数个数据的中位数取中间两个之一。** 错误原因：忘记取平均值。如 $2,4,6,8$ 的中位数是 $\dfrac{4+6}{2}=5$，不是 $4$ 或 $6$。
3. **把众数的"出现次数"当作众数。** 错误原因：混淆数据与频数。如 $2,2,3,5$ 中 $2$ 出现 $2$ 次最多，众数是 $2$（数据本身），不是 $2$ 次（频数）。

## 第 4 单元｜数据的波动（极差与方差）

### 学习目标

1. 能说出极差与方差的含义，会计算一组数据的极差与方差；
2. 能理解方差的意义——方差越大数据波动越大，方差越小米数据越稳定；
3. 能运用方差比较两组数据的波动程度，并据此作出合理判断与选择。

### 核心知识

**极差。** 一组数据中的最大值减去最小值所得的差，叫这组数据的极差，即极差 $=$ 最大值 $-$ 最小值。极差反映数据的变化范围，计算简单，但只利用了最大值和最小值两个信息，不能反映中间数据的波动情况。

**方差。** 一组数据中各数据与平均数之差的平方的平均数，叫这组数据的方差，记作 $s^2$。计算公式为 $s^2=\dfrac{1}{n}\left[(x_1-\bar{x})^2+(x_2-\bar{x})^2+\cdots+(x_n-\bar{x})^2\right]$，其中 $\bar{x}$ 是平均数，$n$ 是数据个数。方差的计算步骤为：①求平均数；②求各数据与平均数的差；③将各差值平方；④求平方的平均数。

**方差的意义。** 方差反映数据围绕平均数的波动大小：方差越大，数据波动越大、越不稳定；方差越小，数据波动越小、越稳定。当两组数据的平均数相同或相近时，常用方差比较其稳定性，方差小的那组更稳定。

**适用边界与易混点。** 极差只看两端，受极端值影响大；方差利用所有数据信息，更全面但计算量大。用方差比较稳定性时，前提是两组数据的平均数相同或相近，平均数不同时不能直接比较方差。

### 常见误区

1. **求极差时不找最大最小值。** 错误原因：用首尾数据代替最大最小值。如数据 $3,7,2,8,5$ 的极差 $=8-2=6$，若用第一个减最后一个 $3-5=-2$，完全错误。必须先找全数据的最大值与最小值。
2. **计算方差时忘记平方或忘记除以 $n$。** 错误原因：公式记忆不牢。方差是"差的平方的平均数"，差值必须取平方（保证非负），最后必须除以数据个数取平均。
3. **平均数不同时直接比方差。** 错误原因：忽视方差比较的前提。若两组数据平均数差异较大，直接比方差没有意义，应结合平均数与方差综合分析。

## 第 5 单元｜随机事件与概率

### 学习目标

1. 能区分必然事件、不可能事件与随机事件，会判断一个事件属于哪一类；
2. 能说出概率的含义，理解概率的取值范围是 $0$ 到 $1$（含端点）；
3. 能用列举法计算简单古典概型的概率，理解"等可能"是使用概率公式的前提。

### 核心知识

**事件的分类。** 在一定条件下，一定会发生的事件叫必然事件，一定不会发生的事件叫不可能事件，可能发生也可能不发生的事件叫随机事件。必然事件和不可能事件统称确定性事件。例如"抛出的石子会落地"是必然事件，"掷一枚骰子朝上点数为 $7$"是不可能事件，"明天会下雨"是随机事件。

**概率的含义。** 随机事件发生的可能性的大小叫概率，记作 $P$。对于等可能事件的古典概型，概率的计算公式为 $P(A)=\dfrac{\text{事件 }A\text{ 包含的结果数}}{\text{所有等可能结果的总数}}$。必然事件的概率为 $1$，不可能事件的概率为 $0$，随机事件的概率满足 $0<P(A)<1$。所有事件的概率都满足 $0\le P\le1$。

**概率的频率解释。** 在大量重复试验中，随机事件发生的频率会稳定在一个常数附近，这个常数就是该事件的概率。概率是理论值，反映了事件发生的固有规律；频率是试验值，随试验次数增大而趋近于概率。少数几次试验的结果不能保证与概率一致。

**适用边界与易混点。** 概率公式 $P(A)=\dfrac{m}{n}$ 的前提是每个结果等可能发生；若各结果不等可能（如灌铅骰子），不能直接套用公式。概率为 $\dfrac{1}{2}$ 不意味着两次试验中一定发生一次，它只表示长期频率趋近于 $\dfrac{1}{2}$。

### 常见误区

1. **把概率等同于"一定会发生"。** 错误原因：误解概率的频率解释。如抛硬币正面概率为 $\dfrac{1}{2}$，不意味着抛两次一定一正一反，实际可能出现两次正面。概率只反映长期频率规律，不保证少数试验的结果。
2. **不等可能事件套用古典概型公式。** 错误原因：忽视"等可能"前提。如一个不均匀骰子各面朝上概率不等，不能直接用 $\dfrac{1}{6}$ 计算各点数概率。
3. **计算概率时分母取错。** 错误原因：把"颜色种类数"当作"总数"。如袋中 $3$ 红 $2$ 白球，摸到红球概率是 $\dfrac{3}{5}$，不是 $\dfrac{1}{2}$（颜色种类数），分母必须是所有球的总数。

## 第 6 单元｜概率的简单计算

### 学习目标

1. 能用列举法（直接列举、列表法、树状图法）计算一步或两步实验的概率；
2. 能区分"放回"与"不放回"两种情形对概率的影响，在摸球等问题中正确计算；
3. 能综合运用概率知识解决游戏公平性等实际问题，并判断方案的合理性。

### 核心知识

**列举法求概率。** 当试验结果有限且每个结果等可能发生时，可以通过列举所有可能结果来计算概率。一步试验可用直接列举法，把所有可能结果逐一列出；两步试验（如连续掷两次、摸两球等）可用列表法或树状图法，系统地列出所有组合结果。

**列表法与树状图法。** 列表法适用于两步试验：把第一步的所有结果作为行、第二步的所有结果作为列，在交叉处填上组合结果，适合每步结果较少的情况。树状图法适用于两步或三步试验：从起点出发画分支表示第一步的所有可能，再从每个分支末端画分支表示第二步，依此类推，所有路径末端就是全部可能结果。

**放回与不放回。** 摸球问题中，"放回"指每次摸出后放回袋中再摸下一次，每次摸球时袋中球的组成不变，各次试验独立；"不放回"指摸出后不再放回，袋中球的组成逐次变化，各次试验不独立。两种情形下，所有等可能结果的总数不同，概率也不同，必须分清条件再计算。

**适用边界与易混点。** 列举时必须做到"不重不漏"：每个结果只列一次，所有结果都要列全；列表法适用于两步试验且每步结果数较少时，三步及以上试验宜用树状图法；"放回"与"不放回"的区别直接影响概率，审题时要先确认条件。

### 常见误区

1. **列举时遗漏或重复结果。** 错误原因：没有系统方法。如掷两枚骰子应列 $6\times6=36$ 种结果，随意列举容易遗漏。用列表法或树状图法能系统列出所有结果，避免遗漏。
2. **混淆"放回"与"不放回"。** 错误原因：审题不仔细。袋中 $3$ 红 $2$ 白球，第一次摸红球后放回，第二次摸红球概率仍为 $\dfrac{3}{5}$；不放回则为 $\dfrac{2}{4}=\dfrac{1}{2}$，两者不同。
3. **两步试验中把有序与无序混用。** 错误原因：不理解等可能的含义。如"同时摸两球"是无序组合，"先摸后摸"是有序排列，两种列法均可，但不能混用导致部分结果重复计数。

### 小结

1. 列举法求概率的关键是"不重不漏"：一步试验直接列举，两步试验用列表法或树状图法系统列出所有结果。
