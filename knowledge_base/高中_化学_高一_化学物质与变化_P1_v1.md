## 第 1 单元｜物质的分类与分散系

### 学习目标

1. 能根据物质的组成和性质对常见物质进行分类，说出单质、氧化物、酸、碱、盐的定义及判别依据；
2. 能理解分散系的概念，根据分散质粒子的大小区分溶液、胶体和浊液，说出胶体的特征性质；
3. 能说明氢氧化铁胶体的制备方法与实验注意事项，理解胶体与溶液的本质区别。

### 核心知识

**物质的分类。** 根据组成物质的种类，可将物质分为纯净物与混合物。纯净物按所含元素种类分为单质（由同种元素组成，如 O₂、Fe）和化合物（由不同种元素组成，如 H₂O、NaCl）。化合物可进一步分为无机物和有机物。无机物主要包括氧化物（由两种元素组成、其中一种是氧元素，如 CO₂、CaO）、酸（电离时阳离子全部是 H⁺，如 HCl、H₂SO₄）、碱（电离时阴离子全部是 OH⁻，如 NaOH、Ca(OH)₂）、盐（由金属离子或铵根离子与酸根离子组成，如 NaCl、Na₂CO₃、NH₄NO₃）。要注意：含氧元素的化合物不一定是氧化物（如 H₂SO₄ 含三种元素），酸式盐（如 NaHCO₃）和碱式盐也属于盐类。

**分散系。** 分散系是指把一种或多种物质以微小粒子的形式分散到另一种物质中所形成的混合物。被分散的物质叫分散质，起容纳作用的物质叫分散剂。根据分散质粒子直径的大小，分散系分为三类：**溶液**（分散质粒子直径小于 1 nm，粒子以分子或离子的形式分散，均一、稳定）、**胶体**（分散质粒子直径在 1 ~ 100 nm 之间）、**浊液**（分散质粒子直径大于 100 nm，不稳定、不均一）。三种分散系中，溶液与胶体外观上都较均匀、较稳定，但本质区别是分散质粒子的大小不同。

**胶体的性质。** ①丁达尔效应：用一束光通过胶体时，可观察到一条明亮的光路，这是胶体粒子对光的散射所致，可用于鉴别溶液与胶体；②电泳：在外加电场作用下，胶体粒子向某一电极定向移动，说明胶体粒子带有电荷（注意：胶体粒子带电，但胶体本身呈电中性）；③聚沉：使胶体粒子聚集成较大颗粒沉降下来的过程。聚沉的方法有加电解质、加带相反电荷胶粒的胶体、加热等。胶体在日常生活和工业中应用广泛，如豆浆、牛奶、墨水、有色玻璃等都是胶体。

**氢氧化铁胶体的制备。** 向沸水中逐滴加入饱和 FeCl₃ 溶液，继续加热至液体呈红褐色时停止加热，即得 Fe(OH)₃ 胶体。化学方程式为：FeCl₃ + 3H₂O —△→ Fe(OH)₃（胶体） + 3HCl。该反应是 FeCl₃ 的水解反应，属于复分解反应。实验注意事项：①必须用饱和 FeCl₃ 溶液而非稀溶液；②必须加到沸水中而非冷水，利用水解吸热的特点促进水解；③加热至红褐色后立即停止加热，不可过度加热，否则胶体易聚沉。

### 常见误区

1. **把丁达尔效应当作胶体与溶液的本质区别。** 错误原因：混淆"特征性质"与"本质区别"。胶体与溶液的本质区别是分散质粒子的大小不同（直径是否在 1 ~ 100 nm 之间），丁达尔效应只是因粒子大小差异而表现出的特征性质，可用于鉴别但不是本质区别。
2. **认为胶体带电。** 错误原因：混淆"胶体"与"胶体粒子"。胶体本身呈电中性（正负电荷总数相等），只有胶体粒子（分散质）带有电荷。如 Fe(OH)₃ 胶体粒子带正电荷，但整个胶体体系呈电中性。
3. **把含氧元素的化合物都当作氧化物。** 错误原因：忽略"两种元素"的限制。如 KClO₃ 含三种元素，不属于氧化物；NaOH 也不属于氧化物。氧化物必须由两种元素组成且其中一种是氧元素。

### 题目 4｜化学方程式题｜难度 3
- 题目编号：GZ-HX-WZB-004
- 学段：高中
- 年级：高一
- 学科：化学
- 题型：化学方程式题
- 模型粗粒度题型：解答题
- 一级知识点：化学::化学基本概念和基本理论
- 细粒度知识点：物质的分类与分散系
- 难度：3
- 认知层次：应用
- 建议作答时长：6 分钟
- 题干：
  实验室制备氢氧化铁胶体的方法是：向沸水中逐滴加入饱和 FeCl₃ 溶液，继续加热至液体呈红褐色后停止加热。
  （1）写出制备 Fe(OH)₃ 胶体的化学方程式，并指出反应条件。
  （2）该反应属于什么基本反应类型？
  （3）如何用实验方法证明所得液体是胶体而非溶液？
  （4）若向所得 Fe(OH)₃ 胶体中逐滴加入过量稀硫酸，会观察到什么现象？说明原因，并写出沉淀溶解的化学方程式。
- 选项：
  无
- 参考答案：
  （1）FeCl₃ + 3H₂O —△→ Fe(OH)₃（胶体） + 3HCl，反应条件为加热（△）。
  （2）该反应属于复分解反应（也属于水解反应）。
  （3）用激光笔（或手电筒）从侧面照射烧杯中的液体，若观察到一条明亮的光路（丁达尔效应），则证明所得液体是胶体。
  （4）现象：先产生红褐色沉淀，继续滴加稀硫酸后沉淀逐渐溶解。
  原因：稀硫酸是电解质，加入后使胶体聚沉，Fe(OH)₃ 胶体聚沉为红褐色沉淀；继续加入过量的稀硫酸后，H⁺ 与 Fe(OH)₃ 发生中和反应使沉淀溶解。
  沉淀溶解的化学方程式：2Fe(OH)₃ + 3H₂SO₄ → Fe₂(SO₄)₃ + 6H₂O。
- 解析：
  （1）FeCl₃ 水解生成 Fe(OH)₃ 和 HCl，需标明加热条件和"胶体"字样。配平：左右 Fe、Cl、H、O 原子数均相等。
  （2）FeCl₃ 与 H₂O 交换成分生成 Fe(OH)₃ 和 HCl，属于复分解反应中的水解反应。
  （3）利用丁达尔效应鉴别胶体与溶液，须写清操作（光照）与现象（光路）。
  （4）电解质使胶体聚沉是胶体的典型性质；过量的酸与碱（Fe(OH)₃ 具有一定的碱性）反应使沉淀溶解，体现了酸碱中和。
  易错点：（1）漏写"胶体"或漏写加热条件；（4）只写沉淀不写溶解过程，或沉淀溶解的方程式未配平。
- 评分要点：
  总分 8 分。（1）化学方程式正确 2 分（反应物与生成物 1 分、配平与条件 1 分）；（2）反应类型正确 1 分；（3）操作与现象各 1 分，共 2 分；（4）现象 1 分、原因 1 分、溶解的化学方程式配平正确 1 分，共 3 分。
- 标签：高中；高一；化学；化学::化学基本概念和基本理论；物质的分类与分散系；化学方程式题；难度3

### 小结

1. 物质分类要依据组成：单质看元素种类、酸碱盐看电离特征、氧化物看元素种类和含氧。
2. 三种分散系的区分依据是分散质粒子直径：溶液 < 1 nm、胶体 1 ~ 100 nm、浊液 > 100 nm。
3. 丁达尔效应是鉴别胶体与溶液的简便方法，但本质区别是粒子大小而非丁达尔效应本身。
4. Fe(OH)₃ 胶体的制备须用饱和 FeCl₃ 溶液加到沸水中，加热至红褐色即停。

## 第 2 单元｜离子反应与离子方程式

### 学习目标

1. 能说出电解质与非电解质的概念，区分强电解质与弱电解质，判断常见物质的类别；
2. 能理解离子反应的本质，掌握离子方程式的书写步骤与书写规则；
3. 能判断离子在溶液中能否大量共存，说出离子反应发生的条件。

### 核心知识

**电解质与非电解质。** 在水溶液中或熔融状态下能导电的化合物叫电解质，如酸（HCl、H₂SO₄）、碱（NaOH、Ca(OH)₂）、盐（NaCl、KNO₃）、活泼金属氧化物（Na₂O、CaO）等。在水溶液和熔融状态下均不能导电的化合物叫非电解质，如蔗糖、酒精、CO₂、SO₂、NH₃ 等。注意：①电解质和非电解质都必须是化合物，单质（如 Cu、Cl₂）和混合物（如盐酸、NaCl 溶液）既不是电解质也不是非电解质；②CO₂、SO₂、NH₃ 等溶于水后溶液能导电，但它们本身不能电离，导电的是与水反应生成的 H₂CO₃、H₂SO₃、NH₃·H₂O，因此 CO₂、SO₂、NH₃ 是非电解质。

**强电解质与弱电解质。** 在水溶液中能完全电离的电解质叫强电解质，包括强酸（HCl、H₂SO₄、HNO₃）、强碱（NaOH、KOH、Ba(OH)₂）、大多数盐（NaCl、BaSO₄、AgCl 等，包括难溶盐）。在水溶液中只能部分电离的电解质叫弱电解质，包括弱酸（CH₃COOH、H₂CO₃、HClO）、弱碱（NH₃·H₂O、Cu(OH)₂ 等）、水和少数盐类。难溶的盐（如 BaSO₄、AgCl）虽难溶，但已溶解的部分完全电离，所以仍是强电解质。

**离子反应的本质与条件。** 离子反应是指有离子参加或有离子生成的反应。在水溶液中，电解质之间发生的反应实质上是离子之间的反应。离子反应发生的条件是：生成沉淀、生成气体或生成弱电解质（如水、弱酸、弱碱），即使溶液中某些离子的浓度减小。若反应后溶液中各离子浓度不变，则不能发生离子反应。

**离子方程式的书写。** 书写步骤（"四步法"）：①写——写出正确的化学方程式；②拆——把易溶于水且易电离的物质（强酸、强碱、可溶性盐）拆成离子形式，而难溶物、气体、弱电解质、氧化物、单质等保持化学式；③删——删去方程式两边相同的离子（即不参加反应的离子）；④查——检查方程式两边各元素原子个数和电荷总数是否相等（即配平）。离子方程式不仅表示一个特定的反应，还可以表示同一类型的离子反应。

**离子共存问题。** 在溶液中，若离子之间能发生反应（生成沉淀、气体或弱电解质，或发生氧化还原反应），则不能大量共存。常见不能共存的组合：①生成沉淀：Ba²⁺ 与 SO₄²⁻、CO₃²⁻；Ag⁺ 与 Cl⁻、CO₃²⁻；Ca²⁺ 与 CO₃²⁻ 等。②生成气体：H⁺ 与 CO₃²⁻、HCO₃⁻、S²⁻ 等。③生成弱电解质：H⁺ 与 OH⁻（生成水）、H⁺ 与 CH₃COO⁻（生成弱酸）等。④氧化还原反应：MnO₄⁻（酸性）与 Cl⁻、Fe²⁺ 与 MnO₄⁻（酸性）等。⑤形成配合物：Fe³⁺ 与 SCN⁻ 等。

### 常见误区

1. **把 CO₂ 等非电解质当作电解质。** 错误原因：只看"溶液能导电"而忽略"谁在导电"。CO₂ 溶于水后溶液能导电，但导电的是 CO₂ 与水反应生成的 H₂CO₃，CO₂ 本身不能电离，是非电解质。
2. **把难溶盐当作弱电解质。** 错误原因：把"难溶"与"难电离"混淆。BaSO₄、AgCl 等虽然难溶，但已溶解的部分完全电离，属于强电解质。
3. **拆离子方程式时把弱电解质也拆开。** 错误原因：不了解"拆"的规则。弱酸（如 CH₃COOH）、弱碱（如 NH₃·H₂O）、水等弱电解质在离子方程式中必须保留化学式，不能拆成离子。

## 第 3 单元｜氧化还原反应的概念与配平

### 学习目标

1. 能从化合价升降和电子转移的角度理解氧化还原反应的本质，区分氧化剂与还原剂；
2. 能用双线桥法或单线桥法表示电子转移的方向和数目；
3. 能掌握氧化还原反应方程式的配平方法（化合价升降法），进行简单的相关计算。

### 核心知识

**氧化还原反应的概念。** 有电子转移（或化合价升降）的化学反应叫氧化还原反应。氧化还原反应的特征是**有元素化合价的变化**，本质是**电子的转移（得失或偏移）**。判断一个反应是否为氧化还原反应，最直观的依据是看反应前后有无元素化合价的改变。如 2Na + Cl₂ —点燃→ 2NaCl 中，Na 从 0 价升到 +1 价、Cl 从 0 价降到 -1 价，是氧化还原反应；而 CaCO₃ —高温→ CaO + CO₂↑ 中各元素化合价不变，不是氧化还原反应。

**氧化剂与还原剂。** 得到电子（化合价降低）的物质叫氧化剂，氧化剂发生还原反应（被还原），具有氧化性；失去电子（化合价升高）的物质叫还原剂，还原剂发生氧化反应（被氧化），具有还原性。记忆口诀："升失氧、降得还"——化合价升高、失去电子、被氧化（是还原剂）；化合价降低、得到电子、被还原（是氧化剂）。常见的氧化剂有 O₂、Cl₂、浓 H₂SO₄、HNO₃、MnO₂、KMnO₄ 等；常见的还原剂有活泼金属（Na、Al、Zn、Fe 等）、H₂、C、CO、I⁻ 等。

**电子转移的表示方法。** ①双线桥法：用箭号从反应物中某一元素指向生成物中同一元素，标注"失去"或"得到"电子的数目，箭号跨过等号。双线桥法能同时表示氧化和还原两个过程。②单线桥法：用箭号从反应物中失电子的元素指向得电子的元素（不跨过等号），标注转移电子的总数。单线桥法只画一条线，表示电子从还原剂转移到氧化剂。

**氧化还原反应的配平。** 配平的依据是：氧化剂得电子的总数等于还原剂失电子的总数（即化合价升降的总数相等），同时满足质量守恒（原子个数守恒）。配平步骤（化合价升降法）：①标出反应前后化合价发生变化的元素的化合价；②找出化合价升高和降低的数值；③求出化合价升降的最小公倍数，确定氧化剂和还原剂的化学计量数；④用观察法配平其他物质的化学计量数；⑤检查各元素原子个数是否相等。

**氧化还原反应的规律。** ①守恒规律：氧化剂得电子总数 = 还原剂失电子总数（用于计算）。②强弱规律：氧化剂的氧化性强于氧化产物，还原剂的还原性强于还原产物（"强还原剂制弱还原剂，强氧化剂制弱氧化剂"）。③归中规律：同种元素不同价态之间发生氧化还原反应时，化合价向中间靠拢（如 2H₂S + SO₂ → 3S + 2H₂O）。④歧化规律：同一物质中同种元素既被氧化又被还原（如 Cl₂ + 2NaOH → NaCl + NaClO + H₂O）。

### 常见误区

1. **把氧化剂说成"发生氧化反应"。** 错误原因：混淆"氧化"与"还原"的概念。氧化剂得到电子，化合价降低，发生的是还原反应（被还原）；还原剂失去电子，化合价升高，发生的是氧化反应（被氧化）。
2. **认为氧化还原反应中一定有氧元素参与。** 错误原因：望文生义。氧化还原反应的本质是电子转移，与是否有氧元素无关。如 2Na + Cl₂ → 2NaCl 是氧化还原反应，但反应中无氧元素。
3. **双线桥法中只标电子数不标"得/失"。** 错误原因：忽略标注的规范性。双线桥法须同时标注"得到"或"失去"以及电子数目，且"得"与"失"的电子总数必须相等。

  本题综合考查氧化还原反应中化合价标注、电子转移表示、氧化剂与还原剂的判断及计算。

  （3）4 mol HCl 中，2 mol 被氧化为 Cl₂（起还原剂作用），2 mol 以 Cl⁻ 形式存在于 MnCl₂ 中（起酸性作用，提供反应所需的酸性环境）。
  （4）计算依据化学方程式中的化学计量数关系，注意区分"参加反应的 HCl"（全部 4 mol 对应 1 mol Cl₂）与"被氧化的 HCl"（2 mol 对应 1 mol Cl₂）。

- 评分要点：

- 标签：高中；高一；化学；化学::化学基本概念和基本理论；氧化还原反应的概念与配平；化学方程式题；难度4

### 小结

1. 氧化还原反应的判断依据是化合价是否改变，本质是电子的转移。
2. "升失氧、降得还"——化合价升高的元素失去电子，被氧化，是还原剂；化合价降低的元素得到电子，被还原，是氧化剂。
3. 双线桥法标注"得/失"电子数目，总数相等；单线桥法只标转移电子总数。
4. 氧化还原计算的核心是守恒规律：氧化剂得电子总数 = 还原剂失电子总数。

## 第 4 单元｜钠、铝、铁及其化合物

### 学习目标

1. 能说出钠、铝、铁的物理性质和化学性质，写出与氧气、水、酸、碱反应的化学方程式；
2. 能说明 Na₂O、Na₂O₂、Na₂CO₃、NaHCO₃ 的性质差异，理解 Al₂O₃ 和 Al(OH)₃ 的两性；
3. 能说出铁的常见氧化物和氢氧化物的性质，理解 Fe²⁺ 与 Fe³⁺ 的相互转化。

### 核心知识

**金属钠的性质。** 钠是银白色金属，质软（可用小刀切割），密度小（ρ ≈ 0.97 g/cm³，比水小、比煤油大，故保存在煤油中），熔点低（约 98 ℃）。钠的化学性质非常活泼：①与 O₂ 反应：常温下表面变暗生成 Na₂O（4Na + O₂ → 2Na₂O）；点燃或加热生成淡黄色 Na₂O₂（2Na + O₂ —点燃→ Na₂O₂）。②与水反应：2Na + 2H₂O → 2NaOH + H₂↑，现象为"浮、熔、游、响、红"——钠浮在水面（密度比水小）、熔成小球（反应放热且熔点低）、四处游动（H₂推动）、发出嘶嘶声（H₂逸出）、加酚酞变红（生成NaOH）。③与酸反应：2Na + 2HCl → 2NaCl + H₂↑（比与水反应更剧烈）。

**钠的氧化物。** Na₂O 是白色固体、碱性氧化物，与水反应生成 NaOH（Na₂O + H₂O → 2NaOH），与 CO₂ 反应生成 Na₂CO₃（Na₂O + CO₂ → Na₂CO₃）。Na₂O₂ 是淡黄色固体，其中氧为 -1 价（过氧根 O₂²⁻），既有氧化性又有还原性。Na₂O₂ 与水反应：2Na₂O₂ + 2H₂O → 4NaOH + O₂↑；与 CO₂ 反应：2Na₂O₂ + 2CO₂ → 2Na₂CO₃ + O₂。这两个反应中 Na₂O₂ 既作氧化剂又作还原剂（O 从 -1 价变为 -2 价和 0 价），属于歧化反应。Na₂O₂ 可用作供氧剂（潜水艇、太空舱）和漂白剂。

**Na₂CO₃ 与 NaHCO₃。** 俗名：Na₂CO₃ 叫纯碱、苏打，NaHCO₃ 叫小苏打。两者都能与酸反应放出 CO₂，但 NaHCO₃ 反应更剧烈：NaHCO₃ + HCl → NaCl + H₂O + CO₂↑。Na₂CO₃ 受热不分解，NaHCO₃ 受热易分解：2NaHCO₃ —△→ Na₂CO₃ + H₂O + CO₂↑。NaHCO₃ 可与碱反应：NaHCO₃ + NaOH → Na₂CO₃ + H₂O。Na₂CO₃ 溶液因水解呈碱性，NaHCO₃ 溶液碱性更弱。侯氏制碱法（联合制碱法）以 NaCl、CO₂、NH₃ 为原料制取 NaHCO₃。

**铝及其化合物。** 铝是银白色轻金属，导电性好、延展性好。铝的化学性质活泼：①与 O₂ 反应：4Al + 3O₂ —点燃→ 2Al₂O₃，放出大量热。②与酸反应：2Al + 6HCl → 2AlCl₃ + 3H₂↑。③与强碱反应（铝的特性）：2Al + 2NaOH + 2H₂O → 2NaAlO₂ + 3H₂↑，说明铝是两性金属。④铝热反应：2Al + Fe₂O₃ —高温→ 2Fe + Al₂O₃，用于焊接铁轨、冶炼难熔金属。Al₂O₃ 和 Al(OH)₃ 都是两性化合物，既能与酸反应又能与碱反应。Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O；Al₂O₃ + 2NaOH → 2NaAlO₂ + H₂O。Al(OH)₃ + 3HCl → AlCl₃ + 3H₂O；Al(OH)₃ + NaOH → NaAlO₂ + 2H₂O。Al(OH)₃ 的制备：向铝盐溶液中加氨水（Al³⁺ + 3NH₃·H₂O → Al(OH)₃↓ + 3NH₄⁺），不能用强碱（过量会溶解沉淀）。

**铁及其化合物。** 铁是银白色金属（粉末为黑色），有磁性。铁的常见氧化物：FeO（黑色）、Fe₂O₃（红棕色，俗称铁红）、Fe₃O₄（黑色，具有磁性，可看作 FeO·Fe₂O₃）。铁与弱氧化剂（如 S、HCl、CuSO₄）反应生成 Fe²⁺；与强氧化剂（如 Cl₂、稀 HNO₃）反应生成 Fe³⁺。Fe(OH)₂ 为白色沉淀，极易被氧化：4Fe(OH)₂ + O₂ + 2H₂O → 4Fe(OH)₃（白色→灰绿色→红褐色）。Fe(OH)₃ 为红褐色沉淀，受热分解：2Fe(OH)₃ —△→ Fe₂O₃ + 3H₂O。Fe²⁺ 与 Fe³⁺ 的相互转化：Fe²⁺ → Fe³⁺ 需加氧化剂（如 Cl₂、稀 HNO₃）；Fe³⁺ → Fe²⁺ 需加还原剂（如 Fe、Cu）。检验 Fe³⁺ 用 KSCN 溶液，现象为溶液变血红色（Fe³⁺ + 3SCN⁻ → Fe(SCN)₃）；检验 Fe²⁺ 可先加 KSCN（不变红），再加氯水（变红）。

### 常见误区

1. **认为 Na₂O₂ 中氧的化合价为 -2。** 错误原因：未理解过氧根的结构。Na₂O₂ 中存在过氧键 O₂²⁻，每个 O 为 -1 价（而非 -2 价），因此 Na₂O₂ 既有氧化性又有还原性。
2. **认为铝只与酸反应不与碱反应。** 错误原因：忽略铝的两性。铝既能与酸反应生成铝盐和 H₂，也能与强碱反应生成偏铝酸盐和 H₂，是两性金属。
3. **把 Fe₃O₄ 当作纯净的 Fe₂O₃ 或 FeO。** 错误原因：不了解 Fe₃O₄ 的组成。Fe₃O₄ 可看作 FeO·Fe₂O₃，其中铁既有 +2 价又有 +3 价，是混合价态氧化物。

  2Na₂O₂ + 2CO₂ → 2Na₂CO₃ + O₂（有 O₂ 生成）。
  原因：Na₂O 中 O 为 -2 价，与 CO₂ 反应时 O 的化合价不变，无氧化还原反应发生；Na₂O₂ 中 O 为 -1 价，与 CO₂ 反应时部分 O 从 -1 价降为 -2 价（进入 Na₂CO₃），部分 O 从 -1 价升为 0 价（生成 O₂），所以 Na₂O₂ 既作氧化剂又作还原剂（歧化反应），有 O₂ 生成。
  （3）潜水艇中人体呼出的 CO₂ 与 Na₂O₂ 反应：2Na₂O₂ + 2CO₂ → 2Na₂CO₃ + O₂，既吸收 CO₂ 又产生 O₂，实现密闭环境中气体的循环利用。

- 解析：
  本题通过对比 Na₂O 和 Na₂O₂ 的性质差异，考查过氧化钠的特殊性质。Na₂O 是普通碱性氧化物，O 为 -2 价，反应中化合价不变；Na₂O₂ 含过氧根（O₂²⁻），O 为 -1 价，反应中发生歧化（部分升为 0 价，部分降为 -2 价），因此既有氧化性又有还原性。
  易错点：（2）只写方程式不从化合价角度分析；（4）把 Na₂O₂ 的歧化反应误判为只作氧化剂或只作还原剂。

## 第 5 单元｜无机非金属材料与硅

### 学习目标

1. 能说出硅元素在自然界中的存在形式，了解硅单质的性质和用途；
2. 能说明 SiO₂ 的化学性质，写出与氢氟酸、强碱反应的化学方程式；
3. 能了解硅酸的制备方法与性质，知道硅酸盐工业（玻璃、水泥、陶瓷）的基本原理。

### 核心知识

**硅的存在与性质。** 硅是地壳中含量第二多的元素（约 26.3%，仅次于氧 48.6%），在自然界中以化合态（主要是硅酸盐和二氧化硅）存在，无游离态。晶体硅是灰黑色、有金属光泽的固体，硬度较大、熔点较高，是良好的半导体材料，可用于制造太阳能电池、芯片（集成电路）等。高纯硅的制备：工业上先用碳还原 SiO₂ 制取粗硅（SiO₂ + 2C —高温→ Si + 2CO↑），再经提纯得到高纯硅。

**二氧化硅。** SiO₂ 是一种坚硬难溶的固体，不溶于水，常温下化学性质稳定。水晶、石英、沙子的主要成分都是 SiO₂。SiO₂ 的化学性质：①酸性氧化物：与碱性氧化物反应（SiO₂ + CaO —高温→ CaSiO₃），与强碱反应（SiO₂ + 2NaOH → Na₂SiO₃ + H₂O）；②与氢氟酸反应（SiO₂ + 4HF → SiF₄↑ + 2H₂O），这是 SiO₂ 的特性反应，可用于雕刻玻璃，所以氢氟酸不能用玻璃容器盛装而用塑料瓶；③与碳酸盐反应（SiO₂ + Na₂CO₃ —高温→ Na₂SiO₃ + CO₂↑），工业上制玻璃的原理之一。SiO₂ 的用途：制造光导纤维（高纯度 SiO₂）、玻璃、石英玻璃（耐高温、透紫外光）、建筑材料等。

**硅酸与硅酸盐。** 硅酸（H₂SiO₃）是不溶于水的弱酸，其酸性比碳酸还弱，不能由 SiO₂ 与水直接反应制取（SiO₂ 不溶于水也不与水反应）。硅酸的制备：向水玻璃（Na₂SiO₃ 溶液）中加盐酸（Na₂SiO₃ + 2HCl → H₂SiO₃↓ + 2NaCl），生成白色胶状沉淀。硅酸受热分解：H₂SiO₃ —△→ SiO₂ + H₂O。硅酸盐是硅酸及其缩水产物所形成的盐的统称，绝大多数硅酸盐难溶于水。常见的可溶性硅酸盐是硅酸钠（Na₂SiO₃），其水溶液俗称水玻璃，具有防火、防腐作用。硅酸盐可用氧化物的形式表示组成，如 Na₂SiO₃ 写作 Na₂O·SiO₂，高岭石 Al₂(Si₂O₅)(OH)₄ 写作 Al₂O₃·2SiO₂·2H₂O。

**硅酸盐工业。** ①玻璃：原料为石英砂（SiO₂）、石灰石（CaCO₃）、纯碱（Na₂CO₃），在玻璃熔炉中高温熔融，主要反应为 Na₂CO₃ + SiO₂ —高温→ Na₂SiO₃ + CO₂↑，CaCO₃ + SiO₂ —高温→ CaSiO₃ + CO₂↑，主要成分为 Na₂SiO₃、CaSiO₃ 和 SiO₂。普通玻璃不是晶体，没有固定熔点。②水泥：原料为石灰石和黏土，在水泥窑中高温煅烧后加入适量石膏磨细。水泥具有水硬性，遇水凝结硬化。③陶瓷：原料为黏土，经混合、成型、干燥、烧结等工艺制得。陶瓷具有耐高温、耐酸碱、绝缘等特性。

### 常见误区

1. **认为 SiO₂ 能与水反应生成硅酸。** 错误原因：把 SiO₂ 当作普通酸性氧化物。SiO₂ 不溶于水，也不与水直接反应。硅酸需通过可溶性硅酸盐与酸反应制取。
2. **认为玻璃是纯净物。** 错误原因：不了解玻璃的组成。普通玻璃是 Na₂SiO₃、CaSiO₃ 和 SiO₂ 的混合物，不是纯净物，没有固定熔点。
3. **用玻璃瓶盛装氢氟酸。** 错误原因：忽略 SiO₂ 与 HF 的反应。氢氟酸与玻璃中的 SiO₂ 反应生成 SiF₄ 气体，腐蚀玻璃，因此氢氟酸须用塑料瓶盛装。

## 第 6 单元｜氯气及卤素

### 学习目标

1. 能说出氯气的物理性质，描述氯气与金属、非金属、水、碱反应的现象，写出化学方程式；
2. 能掌握氯气的实验室制法（原理、装置、收集、尾气处理），理解漂白粉的制备与漂白原理；
3. 能了解卤素单质氧化性的递变规律，掌握卤素离子的检验方法。

### 核心知识

**氯气的物理性质。** 氯气（Cl₂）在通常状况下是黄绿色、有刺激性气味、有毒的气体，密度比空气大（Cl₂ 的摩尔质量为 71 g/mol，空气约为 29 g/mol），能溶于水（1 体积水约溶解 2 体积 Cl₂）。氯气有毒，吸入少量会刺激呼吸道，吸入大量会中毒致死，因此实验室制取氯气时须在通风橱中进行，并须用碱液吸收尾气。

**氯气的化学性质。** 氯气的化学性质活泼，具有强氧化性。①与金属反应：与活泼金属（如 Na）反应：2Na + Cl₂ —点燃→ 2NaCl；与不活泼金属（如 Cu、Fe）反应：Cu + Cl₂ —点燃→ CuCl₂（产生棕黄色烟），2Fe + 3Cl₂ —点燃→ 2FeCl₃（产生棕褐色烟）。注意：Cl₂ 氧化性强，与变价金属（如 Fe）反应时总是生成高价态金属氯化物（FeCl₃ 而非 FeCl₂）。②与非金属反应：H₂ + Cl₂ —点燃→ 2HCl（安静燃烧，发出苍白色火焰）；H₂ + Cl₂ —光照→ 2HCl（混合气体光照发生爆炸）。③与水反应：Cl₂ + H₂O ⇌ HCl + HClO（可逆反应，部分 Cl₂ 与水反应），生成的次氯酸（HClO）有强氧化性，能杀菌消毒和漂白。④与碱反应：Cl₂ + 2NaOH → NaCl + NaClO + H₂O（常温下反应，用于吸收尾气）；2Cl₂ + 2Ca(OH)₂ → Ca(ClO)₂ + CaCl₂ + 2H₂O（工业制漂白粉）。

**氯水的成分与漂白性。** 氯水是氯气的水溶液，其中含有分子（Cl₂、H₂O、HClO）和离子（H⁺、Cl⁻、ClO⁻ 等）。新制氯水呈浅黄绿色（含 Cl₂），具有漂白性（因含 HClO）、酸性和氧化性。HClO 是弱酸，不稳定，见光易分解：2HClO —光照→ 2HCl + O₂↑，因此新制氯水须保存在棕色试剂瓶中。久置的氯水因 HClO 分解逐渐变为稀盐酸，颜色变浅至无色，不再具有漂白性。干燥的氯气无漂白性（因无 HClO 生成），只有湿润的氯气（或氯水）才有漂白性。

**氯气的实验室制法。** 原理：MnO₂ + 4HCl（浓） —△→ MnCl₂ + Cl₂↑ + 2H₂O（须用浓盐酸、需加热）。装置：固液加热型（圆底烧瓶 + 分液漏斗 + 酒精灯 + 导管）。收集：向上排空气法（Cl₂ 密度比空气大）或排饱和食盐水法（可除去 HCl 杂质）。净化：通过饱和食盐水除去 HCl 气体，通过浓硫酸干燥。尾气处理：用 NaOH 溶液吸收多余 Cl₂（Cl₂ + 2NaOH → NaCl + NaClO + H₂O），防止污染空气。

**漂白粉。** 工业上将 Cl₂ 通入石灰乳[Ca(OH)₂]制取漂白粉：2Cl₂ + 2Ca(OH)₂ → Ca(ClO)₂ + CaCl₂ + 2H₂O。漂白粉是 Ca(ClO)₂ 和 CaCl₂ 的混合物，有效成分是 Ca(ClO)₂（次氯酸钙）。漂白粉的漂白原理：Ca(ClO)₂ 在空气中与 CO₂ 和 H₂O 反应生成 HClO：Ca(ClO)₂ + CO₂ + H₂O → CaCO₃↓ + 2HClO，HClO 具有强氧化性使有色物质褪色。因此漂白粉在空气中放置会因 HClO 分解而失效。

**卤素及其递变规律。** 卤素（F、Cl、Br、I）是第ⅦA 族元素，其单质的氧化性从 F₂ 到 I₂ 依次减弱（F₂ > Cl₂ > Br₂ > I₂），对应的阴离子还原性依次增强（F⁻ < Cl⁻ < Br⁻ < I⁻）。氯气能从溴化物和碘化物中置换出 Br₂ 和 I₂：Cl₂ + 2NaBr → 2NaCl + Br₂，Cl₂ + 2NaI → 2NaCl + I₂。卤素离子的检验：Ag⁺ + Cl⁻ → AgCl↓（白色）、Ag⁺ + Br⁻ → AgBr↓（淡黄色）、Ag⁺ + I⁻ → AgI↓（黄色），三种沉淀均不溶于稀 HNO₃。F₂ 与水反应特殊：2F₂ + 2H₂O → 4HF + O₂↑（F₂ 作氧化剂，将水中的 O 氧化为 O₂，与 Cl₂ 与水的歧化反应不同）。

### 常见误区

1. **认为氯气与铁反应生成 FeCl₂。** 错误原因：忽略氯气的强氧化性。氯气氧化性强，与变价金属反应时总是将金属氧化到最高价态，铁与氯气反应生成 FeCl₃（而非 FeCl₂）。
2. **认为干燥的氯气有漂白性。** 错误原因：混淆干燥氯气与氯水。漂白的有效成分是 HClO，干燥氯气中无 HClO（因 Cl₂ 未与水反应），故无漂白性；只有湿润的氯气或氯水中才有 HClO，才有漂白性。
3. **认为氯气溶于水后全部与水反应。** 错误原因：忽略反应的可逆性。Cl₂ + H₂O ⇌ HCl + HClO 是可逆反应，只有部分 Cl₂ 与水反应，氯水中仍有大量未反应的 Cl₂ 分子。

### 题目 24｜化学方程式题｜难度 4
- 题目编号：GZ-HX-WZB-024
- 学段：高中
- 年级：高一

- 细粒度知识点：氯气及卤素
- 难度：4
- 认知层次：综合
- 建议作答时长：7 分钟
- 题干：
  卤素（F、Cl、Br、I）是周期表中第ⅦA 族元素，其单质的氧化性从 F₂ 到 I₂ 依次减弱。请回答：
  （1）写出氯气分别置换出溴和碘的化学方程式（各一个），并指出反应的现象。
  （2）上述反应说明 Cl₂、Br₂、I₂ 的氧化性强弱顺序是什么？判断依据是什么？
  （3）写出氟气与水反应的化学方程式，该反应与氯气与水反应有何本质区别？
  （4）实验室可用淀粉-KI 试纸检验氯气，写出相关反应的离子方程式并说明现象。
  （5）向含有 NaBr 和 NaI 的混合溶液中通入少量氯气，生成的产物是什么？若通入足量氯气，产物又是什么？请分别说明理由。
- 选项：
  无
- 参考答案：
  （1）Cl₂ + 2NaBr → 2NaCl + Br₂，现象：溶液由无色变为橙红色（或橙黄色）。
  Cl₂ + 2NaI → 2NaCl + I₂，现象：溶液由无色变为褐色（或棕黄色），滴入淀粉溶液后变蓝。
  （2）氧化性：Cl₂ > Br₂ > I₂。判断依据：氯气能把 Br⁻ 和 I⁻ 氧化为 Br₂ 和 I₂（Cl₂ 作氧化剂，Br₂ 和 I₂ 是氧化产物），根据"氧化剂的氧化性强于氧化产物"的规律，Cl₂ 的氧化性强于 Br₂ 和 I₂。
  （3）2F₂ + 2H₂O → 4HF + O₂↑。
  本质区别：F₂ 与水反应时，F₂ 只作氧化剂（F 从 0 价降为 -1 价），将水中的氧元素从 -2 价氧化为 0 价（生成 O₂），不是歧化反应；而 Cl₂ 与水反应（Cl₂ + H₂O ⇌ HCl + HClO）是歧化反应，Cl₂ 既作氧化剂又作还原剂（Cl 从 0 价变为 -1 价和 +1 价）。
  （4）离子方程式：Cl₂ + 2I⁻ → 2Cl⁻ + I₂。现象：淀粉-KI 试纸变蓝（生成的 I₂ 遇淀粉显蓝色）。
  （5）通入少量氯气时：只生成 I₂（不生成 Br₂）。理由：氧化性 Cl₂ > Br₂ > I₂，对应的还原性 I⁻ > Br⁻，氯气优先与还原性更强的 I⁻ 反应（Cl₂ + 2I⁻ → 2Cl⁻ + I₂）。
  通入足量氯气时：生成 I₂ 和 Br₂。理由：氯气先与 I⁻ 反应（Cl₂ + 2I⁻ → 2Cl⁻ + I₂），I⁻ 反应完后，过量的氯气继续与 Br⁻ 反应（Cl₂ + 2Br⁻ → 2Cl⁻ + Br₂），因此足量氯气可将两者都氧化。
- 解析：
  本题综合考查卤素单质的氧化性递变规律及其应用。
  （1）置换反应须配平并说明现象，注意 I₂ 遇淀粉变蓝的特征。
  （2）利用"强氧化剂 + 强还原剂 → 弱氧化剂 + 弱还原剂"的规律判断氧化性强弱。
  （3）F₂ 与水的反应是 F₂ 的特性反应，与 Cl₂ 与水的歧化反应本质不同：F₂ 只作氧化剂，Cl₂ 既作氧化剂又作还原剂。
  （4）利用 Cl₂ 的氧化性将 I⁻ 氧化为 I₂，I₂ 使淀粉变蓝，这是检验 Cl₂ 的常用方法。
  （5）根据还原性强弱（I⁻ > Br⁻），少量氯气先氧化 I⁻；足量氯气可将 I⁻ 和 Br⁻ 都氧化。此题考查氧化还原反应的先后顺序（"强者优先"原则）。
  易错点：（3）把 F₂ 与水的反应误认为歧化反应；（5）把少量氯气时的产物答成 I₂ 和 Br₂。
- 评分要点：
  总分 10 分。（1）两个方程式各 1 分、两个现象各 0.5 分，共 3 分；（2）氧化性顺序 1 分、判断依据 1 分，共 2 分；（3）化学方程式 1 分、本质区别 1 分，共 2 分；（4）离子方程式 1 分、现象 0.5 分，共 1.5 分；（5）少量与足量各 0.75 分（须含产物与理由），共 1.5 分。

### 小结

1. 氯气是黄绿色有毒气体，化学性质活泼，氧化性强，与变价金属反应生成高价态氯化物（如 FeCl₃）。
2. 氯水含 Cl₂、H₂O、HClO 等分子和 H⁺、Cl⁻、ClO⁻ 等离子；漂白的有效成分是 HClO，干燥氯气无漂白性。
3. 实验室制氯气用 MnO₂ + 浓盐酸（加热），须用 NaOH 溶液吸收尾气。
4. 卤素单质氧化性 Cl₂ > Br₂ > I₂，阴离子还原性 I⁻ > Br⁻ > Cl⁻；F₂ 与水反应不是歧化反应，与 Cl₂ 不同。
