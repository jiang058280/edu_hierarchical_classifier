# OCR 人工复核与发布门禁

## 本次完成

处理任务成功只说明技术链路完成，不能证明标题、表格或公式正确。现在教师发布接口会检查最新入库任务：含 OCR 页的资料必须先有人工复核通过记录，否则不改变资料及切片的发布状态。

教师端进入“知识库管理 → 资料处理记录 → 预览”，可查看全部父块识别文本。对照自己保存的上传原件逐项检查正文、标题、表格单元格和数学符号，填写说明，选择通过或不通过。通过前必须显式勾选核对确认。复核通过不会自动发布或激活版本。

接口：`POST /api/v1/teacher/rag/documents/{id}/ocr-review`。提交预览响应中的 token、布尔 approved、note；通过时另需 `checked_source_title_table_math: true`。

## 安全与一致性

- 复核、预览与发布仅允许资料所属教师操作。
- 复核绑定原文件哈希、最新任务 ID、实际父子块内容与关联关系。文本变化、分块替换或新任务会使旧确认失效；旧浏览器页面提交会被拒绝。
- 记录保存在当前入库任务的 metrics_json，含结论、说明、审核人和时间，不新增数据库表或迁移。保存的是当前结论，不是不可变的完整审核历史。
- 已发布资料必须先下架才允许重新复核，避免“复核不通过但仍在线”。
- 最新任务未完成或指标异常时禁止发布。历史 PDF 缺少 OCR 页记录时保守要求复核；没有任何入库任务的 PDF 需先重建。
- 明确记录 `ocr_pages: []` 的原生文本 PDF 和普通文本资料不要求 OCR 专项复核；其他既有发布规则保持不变。

只读核对测试教师 33 的资料 23：状态 PROCESSED，published_at 为空，OCR 页为 [1]，新门禁判断 PENDING。未代替教师点击通过，未发布、未激活版本，未修改正式数据。

后续已重启 7862 测试服务，启动前核对无待执行迁移，新后端已生效。用原测试教师真实登录并通过本地 Chromium 完成预览、未勾选确认拦截和发布拒绝的点击验收。未新增资料、未批准审核、未发布或激活版本。

真实验收报告：`output/ocr_review_acceptance_20260926_retry/report.json`。缺少核对确认和待复核发布均返回 HTTP 400，浏览器无 pageerror；最终资料仍为 PROCESSED / PENDING，版本 STAGED。测试密码仅在内存中用于登录，未导出 Token、浏览器登录状态或密码；后续人工登录该专用账号仍需重置密码。

首次浏览器测试未通过。排查发现教师页会直接选用全局激活版本，即使该版本不在当前教师的版本列表中，导致自己的资料被过滤为空；现已修正为优先保留本人选择、其次选择本人可见的激活版本、否则选择自己的首个版本。第二次明确选择测试版本后通过，另有 JavaScript 回归测试覆盖默认选择逻辑。

页面截图：`output/ocr_review_acceptance_20260926_retry/review-preview.png` 与 `publication-blocked.png`。服务启动记录位于首次运行目录 `output/ocr_review_acceptance_20260926/server.log`，复测复用该进程，没有另起端口。

## 验证范围与剩余工作

新增数据库及 HTTP 集成测试，覆盖未复核拦截、不通过拦截、明确通过后发布、越权拒绝、缺少确认拒绝、错误布尔类型拒绝、旧内容/新任务使审核失效，以及原生文本 PDF 的兼容路径。测试使用隔离测试库，不发布真实样本。

最终全量验证：376 passed，1 个既有 Starlette 弃用警告；发布验收各项通过。Ruff、教师页面内联 JavaScript 语法检查及 OCR 布局 JavaScript 测试通过。

仍需解决数学符号识别歧义、复杂版式与公式专项识别、更多自然扫描样本评测，以及人工验收。当前复核门禁不是自动纠错功能，也不等于 OCR 质量验收通过。已有发布资料不会被本次代码改动自动下架；历史已发布资料应另行审计。
