# 小规模 BM25 + RRF 接入记录

## 实现范围

- 新增确定性 BM25：中文连续片段二元词、英文/数字词，k1=1.2、b=0.75；词频与长度归一化参与评分。
- 向量变体先按最高向量分合并成一路，再与 BM25 路按 RRF 融合；同一路重复 ID 不重复计票，RRF 默认 k=60。
- BM25 从 MySQL 中读取当前请求版本、角色、学科、学段、年级和知识点允许访问的已发布子块；合并候选后再次校验发布状态与权限。
- 独立返回 bm25_score、rrf_score。原 score 仍是向量证据分，BM25-only 候选取 0，因此不会凭关键词排名越过默认 0.55 证据门槛。
- 默认关闭，未修改本机 .env、未启动或重启服务、未发布版本、未重建索引。

## 配置

在完成验收后，部署人员可设置 EDU_RAG_HYBRID_ENABLED=true。EDU_RAG_BM25_MAX_CHUNKS 默认 5000，EDU_RAG_RRF_K 默认 60。

本实现每次请求对已授权语料计算 BM25，适合小规模验收，不是可扩展的倒排索引服务。超出容量直接报错，不静默截取前 5000 条并冒充全量召回。需要更大规模时应迁移到独立关键词索引，继续保留最终 MySQL 授权过滤。

## 尚未完成的边界

- 独立 Reranker 模型尚未接入；RRF 不等于模型重排。
- BM25-only 结果需要经过验证的相关性判定才能支持生成，目前以保守拒答为优先。
- 关键词分词不含专业词典，公式符号检索仍有局限；应根据学科 Bad Case 评估。
- 未进行正式人工金标质量对比与真实服务容量压测，不能声称混合检索已经提升指定百分比。
- Embedding 或 Milvus 出错时仍沿用错误路径，不宣称已支持纯关键词自动容灾。

## 验证

新增 BM25 数值公式、分词、参数、RRF 去重与融合、关键词独立命中、权限过滤及分数隔离测试；扩展 MySQL 隔离测试库上的角色、学段、未发布资料过滤测试。最终全量结果见 reports/verification/v1_release_latest.json。
