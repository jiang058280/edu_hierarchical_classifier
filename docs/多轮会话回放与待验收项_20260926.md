# 多轮会话回放与待验收项

后续状态更新：已补默认关闭的有限主题记忆，见 `docs/会话主题记忆接入_20260926.md`。下方“未使用历史”是接入回放工具时发现的原始状态；复杂指代与真实多轮效果仍待验收。

## 发现的真实缺口

当前 RagConversationService 会校验会话所有者、保存用户问题和助手回答，但 ask / ask_stream 没有读取历史消息再传给回答服务。因此，会话列表里能看到多轮消息，不等于模型能理解“它”“上面那一步”等指代。

本轮补的是真实接口回放与审计工具，不是对话记忆实现。不能据此宣称连续追问效果已经验收。

## 回放流程

1. 从 JSONL 精确选择一条学生 follow_up 用例，验证前序消息按 user/assistant 成对排列。
2. 默认只生成 dry_run 报告，不连接服务，不创建会话，不调用模型。
3. 显式执行时要求 ready=true、隔离测试服务地址、指定测试学生 ID，以及本机环境变量中的登录令牌。
4. GET auth/me 校验身份；GET student/rag/scope 获取服务端普通问答检索范围，核对用例要求的学段和年级。不允许客户端改变检索权限。
5. 第一轮只发送历史用户问题，由接口真正生成回答；后续沿用服务端返回的 session_id。草稿里的 assistant 参考答案不会发送给接口。
6. 所有历史用户问题回放后，再发送当前追问，记录每轮实际回答、来源、消息 ID、首段文本时间和完成时间。
7. 只有收到合法完成事件，且连接正常结束，才标记该轮 completed。整体回放结束标为 replayed_pending_review，不是质量验收通过。

普通问答接口不支持客户端 subject / knowledge_node_id 过滤。报告会在 ignored_filter_keys 显式列出此类字段，保留实际 actual_scope；这类回放不能替代原带学科筛选条件的离线检索评测。

## 使用方式

在项目根目录运行以下命令，只检查现有草稿，输出路径必须尚不存在：

```powershell
.\venv\Scripts\python.exe scripts/replay_rag_conversation.py --dataset output/rag_review_draft_20260926/cases.jsonl --case-id RAG-DRAFT-003 --output reports/verification/my_replay_dry_run.json
```

正式回放须先人工审核并另存评测集，在本机安全地配置 EDU_RAG_REPLAY_TOKEN，不要把令牌发到聊天中或写入脚本。然后使用如下参数结构（占位值需替换）：

```text
python scripts/replay_rag_conversation.py --dataset <已审核JSONL> --case-id <用例ID> --output <新报告路径> --execute --base-url <隔离测试服务的/api/v1前缀> --expected-user-id <测试学生ID>
```

执行会真实写入问答会话与审计记录，可能产生模型费用。工具不自动创建账号、不绕过鉴权、不改资料权限、不删除会话，也不自动重试。网络中断时服务端可能已经保存回答，重跑会新建会话，先检查报告与服务端历史。

非本机地址必须使用 HTTPS；关闭自动重定向和环境代理，防止测试令牌被意外转发。需要代理的部署须另行受控配置。

## 报告与失败语义

- dry_run：仅检查用例与计划轮数，可仍为 ready=false。
- incomplete：请求失败、协议错误、身份/范围不符或缺少 done；退出码 2，不计为成功。保留已获取的会话 ID、半截文本和失败原因。
- replayed_pending_review：接口逐轮回放完成；仍需人工评价正确性、承接上文能力、引用支持程度和拒答是否恰当。
- final_refusal_matches：仅比较最后一轮拒答布尔值，不是任务完成率。
- client_latency_ms：HTTP 调用至流结束的时间；first_token_ms 为客户端收到首段文本的时间，兼容分段展示模式下不等于模型真实首 Token 延迟。
- server_latency_ms：接口自身返回的耗时；与客户端时间范围不同。

接口不返回检索分块排名，因此不计算 Recall、MRR 或 nDCG。每次请求的 120 秒 timeout 是网络操作超时，不是整条会话总时限；本工具不是容量压测工具。

报告包含教学内容和测试会话 ID，应按内部资料保管。本轮只运行草稿 dry-run 和 MockTransport / 本地测试，未使用真实学生令牌，未调用真实模型。异常结束也不能保证进程被强杀后报告完整落盘。
