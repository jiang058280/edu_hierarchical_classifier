# E6 本地容量压测执行说明

压测入口为 `loadtests/locustfile.py`，代码强制限制到 `127.0.0.1/localhost`。账号密码、作业 ID 必须由环境变量或 Locust 参数显式提供，脚本不会创建或清理业务数据。执行前运行 `scripts/prepare_loadtest_fixture.py`，它只允许创建/追加到名称以 `_loadtest` 结尾的隔离库，并在 `reports/loadtest/runtime_fixture.json` 生成不入 Git 的运行参数。

建议使用隔离的压测数据库和专用账号，分别执行：分类 50 并发、交卷 50 并发、RAG 10 并发。交卷场景不能让多个虚拟用户复用同一个学生账号，否则正常的“禁止重复提交”会被误计为容量错误。

结果使用 Locust CSV 输出到 `reports/loadtest/`，报告至少记录请求数、失败率、P50/P95/P99、运行时长、CPU/内存、数据库慢查询和测试夹具说明。

调用 Locust 时应在命令末尾显式指定 `ClassifyUser`、`SubmitUser` 或 `RagUser`；`--tags` 只筛任务，不能用于筛掉其他用户类。交卷场景必须传 `--student-users-file`、`--assignment-id` 和 `--question-id`，50 个账号各执行一次首次提交。隔离实例可临时提高单 IP 限流，业务实例的限流配置不得改变。最后运行 `scripts/build_capacity_report.py` 汇总 CSV、提交落库事实与慢查询样本。
