## 校对内容

对照扫描页核对了全文、表格和公式：将 `k〈 0` 修正为 `k < 0`，`2 X 2` 修正为 `2 × 2`，表头 `X` 修正为 `x`；修正 OCR 字样、样本编号、重复标点和空格。保留原件中的测试用途声明及例题、练习内容。

表格为 x = 0、1、2 对应 y = 1、3、5；计算式 y = 2 × 2 + 1 = 5；练习 y = 3x - 2 在 x = 2 时等于 4，y = -2x + 4 随 x 增大而减小，均核对正确。

校对版是经明确标注的派生文本，不是覆盖 PDF 的文字层，也不是把正确答案偷偷注入 OCR 输出。通过既有 Markdown 上传接口重新解析、分块、Embedding 和入库，避免仅修改 MySQL 正文而向量仍为旧文本。该文件不需要 OCR 专项审批，校对行为另有审计。
