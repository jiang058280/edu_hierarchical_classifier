## 第〇部分 全局约定

### 0.1 每个任务的通用验收前置（下文简称"标准自证"）

1. `venv\Scripts\python -m ruff check .` → 0 违规；
2. `venv\Scripts\python scripts\check_project_guardrails.py` → 通过；
3. `venv\Scripts\python -X utf8 -m pytest tests -q` → 全过（新功能必须带测试）；
4. 浏览器实测所有新增/改动按钮（刷新后测试，防缓存假象）；
5. git 提交（约定前缀），临时脚本与 `_*.py` 不入库。

### 0.2 数据事实（写代码前核对）

- 数据库：MySQL 容器 `edu-classifier-mysql`，宿主 **3307**，root/root123，库 `edu_classifier`；
- 已有表（13）：V1 六表 + schema_migrations + V2（users/audit_logs）+ V3（classes/knowledge_nodes/papers/paper_questions/assignments/submissions/answer_records）——**M2/M3 无需新迁移即可开工**（除非本计划明确新增）；
- users 现有：admin(admin) / stu_test01(student, class_id=2)；
- 模型版本：v0.1-base(Archived) / v0.2-20260906(Archived) / **v0.3-20260906(ACTIVE)**；
- 当前数据：train 9,893 / val 1,917 / **test 1,039（固定基准，任何任务不得改动）**；train 来源：k12edubench 4,829 + cmmlu 836 + m3ke 3,120 + gaokao 1,193 + numina 1,500（去重后）；
- 端口：服务 7860；MySQL 宿主 3307；Milvus 宿主 19531（可降级）。

### 0.3 代码风格与纪律（沿用交接文档第五节全部禁令）

要点重申：页面脚本首行 `const $ = ...`；接口响应读数组加 `|| []` 防御；页面路由只在根路径注册；改表走迁移；**禁止用 PowerShell 内联命令改代码文件**；提交前标准自证；新增数据源登记 `DATA_PROVENANCE.md`。

## 第二阶段 v0.4 模型迭代

### B1 判断题重采样与重训

| 项 | 内容 |
| --- | --- |
| 根因 | v0.3 训练集判断题仅 357/9,893（3.6%），金标 300 里 4 条判断题错 → 宏平均 F1 0.9406→0.8522 |
| 改动文件 | 新建 `scripts/rebalance_train.py`；不改 `build_merged_dataset.py`（其幂等护栏保持） |
| 步骤 | ① rebalance 脚本：读 train.csv，将 `question_type=="判断题"` 行复制 ×4（`text` 不变，追加标记列 `oversampled=1`——或直接复制行，记录复制份数入 merge report），解答题 ×1.5 取整；写回 train.csv 前备份原文件为 `train.pre_rebalance.csv`；② 重跑 `preprocess_all.py` 刷新 data_manifest；③ `train_model.py --version v0.4-20260906 --epochs 7`（GPU ~30 分钟）；④ `rebuild_model_version.py --version v0.4-20260906 --gate --activate` |
| 验收 | 门禁 5/5 PASS；golden 300 题型 F1 ≥ 0.90 且 判断题 F1 明显回升；学科/知识点/级联不低于 v0.3（-0.5pt 内容忍）；激活后浏览器实测分类正常 |
| 回滚 | 任何门禁未过 → v0.3 保持 ACTIVE，v0.4 停 STAGED；已激活后发现异常 → `POST /api/v1/models/rollback` |
| 边界 | oversample 仅复制文本不修改标注；若判断题 F1 仍 <0.8，改用类加权损失（LabelSmoothCE 加 weight 参数）作为 Plan B，另立一轮 |
| 工作量 | 0.5 天准备 + 35 分钟训练 |

- 前端：队列页（题目+预测+作答统计+修正表单）；
- 验收：修正 20 条 → 导出 bad_cases → 回灌演练全通。
