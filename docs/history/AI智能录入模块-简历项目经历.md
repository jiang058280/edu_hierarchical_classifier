## 一、项目背景与介绍

**项目名称**：智慧教研平台 — 题库管理 / AI 智能录入子模块

**项目简介**：
智慧教研平台是一个面向 K12 教研场景的一体化教研工作台，集成题库管理、智能组卷、学情分析、系统设置等模块。本人独立负责"题库管理 → AI 智能录入"子模块的端到端设计与落地实现。

**业务痛点**：
在线教育、智能题库场景中，新题入库需要人工逐题标注 学科 / 题型 / 知识点 三级标签，存在以下问题：
- **标注效率低**：每道题人工标注平均耗时 30s~1min，新题入库形成瓶颈；
- **一致性差**：不同教研员对题型、知识点划分标准不统一，标签质量参差；
- **复核成本高**：题量增长后难以快速回溯分类合理性，缺乏置信度参考。

**模块定位**：
教研员粘贴题目文本后，系统调用本地 BERT 多任务模型自动输出"学科 → 题型 → 知识点"三级标签及各级 Softmax 置信度，教研员确认 / 修正后一键入库，形成 **"自动预标注 + 人工复核"** 的人机协同闭环，目标把单题标注耗时压到秒级。

## 三、个人职责

### 1. 前端界面设计与实现
- 独立设计 AI 智能录入页面 **三段式布局**：顶部输入区、中部分类结果卡片、底部模型统计条；
- 使用 Tailwind CSS 实现面包屑导航、快捷学科示例标签、置信度圆环图、人工反馈按钮组；
- 设计"学科 → 题型 → 知识点"**时间轴可视化**，按置信度阈值（≥90% 绿 / 70~90% 橙 / <70% 红）做语义着色；
- 低置信度（<70%）自动高亮"建议人工复核"提示条，引导教研员介入。

### 2. 后端 API 桥接与数据流
- 将 `app.py` 从纯 Gradio 升级为 **FastAPI + Gradio 混合服务**：Gradio 挂载根路径 `/`，FastAPI 路由挂载 `/api`；
- 设计并实现模块所需 RESTful 接口：
  - `POST /api/classify`：调用模型推理，返回三级标签 + 各级置信度；
  - `POST /api/feedback`：写入 `feedback.jsonl` 并累计计数到 `feedback_counts.json`；
  - `POST /api/save_question`：将确认后的题目及分类标签写入题库；
  - `GET /api/history`：分类历史记录读取，配合前端 localStorage 缓存（上限 30 条）支持一键回填。
- 严格不动核心代码（`src/predict.py` / `src/train.py` / `src/data_loader.py` / `models/heads/*.pt`），仅在 `app.py` 内做桥接扩展。

### 3. 模型推理集成
- 集成预训练 BERT-base-Chinese 多任务模型（共享主干 + 三头），一次前向同时输出学科、题型、知识点三级 Softmax 概率；
- 启用 CPU 动态量化（int8），单条推理由 216ms 降至 125ms（**加速约 42%**）；
- 使用 `@lru_cache` 对相同输入做缓存，避免重复推理；推理全程 `with torch.no_grad()`，固定 `batch_size=1`，规避 CPU 内存溢出；
- 实现 GPU/CPU 自动检测逻辑，无需修改业务代码即可切换硬件。

### 4. 人机协同闭环设计
- 设计并落地 **"自动预标注 → 人工反馈 → 一键入库"** 完整工作流；
- 反馈数据持久化到 `feedback.jsonl` 与 `feedback_counts.json`，可直接作为后续模型迭代 / 主动学习的样本来源；
- "存入题库"操作自动联动题库列表与工作台"今日使用次数"统计，无需刷新页面。

### 5. 交互细节打磨
- 解决原生 `<dialog>` 元素在复杂布局下无法 `showModal()` 的兼容性问题，替换为基于 `classList.add/remove('show')` 的自定义 div 模态框，支持遮罩点击与 ESC 关闭；
- 实现按钮悬浮上浮（translateY）、置信度数字 0→目标值递增动画、进度条 0.5s 过渡；
- 为学科 / 题型筛选下拉框补齐 `change` 事件监听，实现切换后**列表实时刷新**，无需跳转页面再返回；
- 自定义滚动条（6px 宽 / `#4A5CF7` 圆角 thumb）与玻璃拟态卡片（`rgba(255,255,255,0.7)` + `backdrop-filter: blur(12px)`）统一视觉风格。

## 四、项目优点与成果数据

### 1. 项目优点

1. **架构清晰**：共享主干 + 多任务三头结构，相比串行级联方案推理时间下降约 60%；
2. **性能优异**：CPU 动态量化 + `lru_cache` + `no_grad` 三重优化，单条推理 < 3 秒，完全满足交互响应需求；
3. **人机协同**：自动预标注 + 人工复核 + 反馈采集闭环，兼顾效率与准确性，反馈数据可反哺模型迭代；
4. **可视化优秀**：SVG 圆环 + 时间轴 + 颜色编码，三级置信度一目了然，低置信度自动提示人工复核；
5. **即时反馈**：所有操作（输入、反馈、入库、筛选、删除）实时响应，无需页面跳转；
