# 智慧教研平台建设计划书 · 当前里程碑索引

更新：2026-09-09。原同名计划在当前工作区不存在；本文件是当前状态索引，不是历史全文恢复。详细规格、依赖和验收口径统一见 [剩余工作总计划](剩余工作总计划.md)。

| 里程碑 | 当前状态 | 交付边界 |
| --- | --- | --- |
| M0 / M1 | 已实现 | 师生登录、班级、题库、AI 标签、组卷 |
| M2 / C1～C4 | 已实现，用户已确认继续 | 判分、作业发布与批改、学生作答及蓝灰新版首页 |
| M2 / C5 | 集成验收，等待用户确认 | 真实账号与20题闭环、权限/截止/并发、375px浏览器与标准发布检查 |
| R1 | 未开始 | 教育知识库、资料解析、审核、版本与检索入库 |
| R2 | 未开始 | 基于来源的 RAG 问答、引用校验、拒答与反馈 |

| M4 / M1.5 | 后续 | 治理加固、压测与批量数据通道 |

当前成绩口径：自动分为可判客观题正确率，主观题自评独立标识，最终分由教师确认。题目引用受保护，现阶段不支持在已组卷的原题上覆盖修改。

证据入口：`reports/verification/v1_release_latest.json` 与 `reports/verification/m2qa_*/m2_acceptance.json`。每模块交付后先供用户检查；确认前不进入下一模块，不混合提交用户原有改动。
